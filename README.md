# Java Number Guessing Game

A beginner-friendly console game written in Java. The computer chooses a secret number from 1 to 100, and the player guesses until they find it.

## Features

- Random number from 1 to 100
- “Too high” and “too low” hints
- Checks that input is a whole number in the allowed range
- Counts valid guesses

## Requirements

- Java Development Kit (JDK) installed

## How to run

1. Open a terminal in the folder containing `NumberGuessingGame.java`.
2. Compile the program:

   ```bash
   javac NumberGuessingGame.java
   ```

3. Run it:

   ```bash
   java NumberGuessingGame
   ```

## Java concepts used

`Scanner` for keyboard input, `Random` for the secret number, a `while` loop, `if/else` conditionals, input validation, and a counter.
